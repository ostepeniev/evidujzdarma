# Правила для кодових сесій

## Ролі

- **Власник** (Олег) ухвалює лише рішення про гроші, ринок, смак і незворотні кроки.
- **Контролер** (Cowork) планує, пише задачі в `docs/tasks/`, рецензує по коду, веде `docs/DECISIONS.md`, `docs/LATER.md` і `docs/INDEX-FOR-NEW-SESSION.md`. Код пише лише за окремою вказівкою власника.
- **Кодова сесія** бере блок цілком і пише код, тести й технічну документацію.

## Як працюємо

1. Перед кодом — абзац «що вже є» з прочитаного коду (не з пам'яті й не з документів).
2. Гейт червоним першим: тест або сценарій, що падає до виправлення.
3. Блок робиться цілком. Зупинка лише на **ЧЕКПОІНТ** (гроші, ринок, смак, незворотне). Уночі чекпоінт без відповіді не зупиняє: пункт лишається відкритим у звіті, а сесія йде далі по незалежному.
4. Інваріанти з `AGENTS.md` і рішення з `docs/DECISIONS.md` не порушуються. Якщо рішення заважає — записати в звіт і продовжити по іншому.
5. Факти про закон — лише з першоджерелом (eet.gov.cz, financnisprava.gov.cz, app.fs.gov.cz, текст закону). Центральне місце — `apps/web/src/content/facts.ts`.
6. Перед кожним комітом: `pnpm -r test`, `pnpm -r typecheck` (у web — після `next typegen`). Обидва зелені.
7. Гілка робіт — `claude/pensive-mayer-wcam12`. У `main` не пушимо. Паралельна сесія — лише з окремою гілкою за вказівкою контролера.

## Файли

| Файл | Хто пише |
| --- | --- |
| `docs/tasks/<дата>-<блок>.md` | контролер: задача або рецензія |
| `docs/tasks/<задача>.report.md` | кодова сесія: звіти після комітів |
| `docs/tasks/<задача>.notes.md` | кодова сесія: знахідки, питання |
| `docs/DECISIONS.md` | контролер; кодова сесія дописує свої технічні рішення в кінець секції **Т** з позначкою «С» |
| `docs/LATER.md`, `docs/INDEX-FOR-NEW-SESSION.md` | контролер |
| `docs/research/*` | обидва; факти — з джерелом і датою |

## Формат звіту (після кожного коміту, у `<задача>.report.md`)

1. Коміти: sha і що зроблено.
2. Було → стало по кожному пункту задачі, з файл:рядок. Міграції: номер і що відбувається з наявними даними.
3. Гейти, що були червоними до коду, і на чому саме вони падали.
4. **Самостійні рішення** (яких не було в задачі) — окремим списком.
5. Що не вдалося і чому. Що потрібно від власника — дослівні команди або тексти.
