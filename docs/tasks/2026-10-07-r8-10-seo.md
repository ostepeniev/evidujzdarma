## S1.1 IndexNow (Seznam і Bing; Google не підтримує)

- Ключ: 32 символи `[a-f0-9]`; файл `apps/web/public/<ключ>.txt` лише з ключем (UTF-8, без BOM і переносу рядка). Ключ публічний за протоколом, не секрет.
- Скрипт `apps/web/scripts/indexnow.ts` (`pnpm --filter web indexnow -- --since <ISO> | --all | --url <URL>...`): бере `https://evidujzdarma.cz/sitemap.xml`, вибирає URL з `lastmod >= since` (або всі) і шле POST JSON `{host: "evidujzdarma.cz", key, keyLocation: "https://evidujzdarma.cz/<ключ>.txt", urlList}` на `https://search.seznam.cz/indexnow` (`Content-Type: application/json; charset=utf-8`). Друкує код відповіді: 200/202 — ok; 403, 422, 429 — зрозуміле повідомлення. Деплой не валить: exit 0, крім помилки аргументів.
- Жодного cron і жодного виклику з рантайму сайту: скрипт запускає контролер після деплою.
- **Гейт:** payload містить лише `https://evidujzdarma.cz/...`, не більше 10 000 URL, host збігається; ключ 8–128 символів `[A-Za-z0-9-]`; вміст `public/<ключ>.txt` = ключ; фільтр за lastmod.
